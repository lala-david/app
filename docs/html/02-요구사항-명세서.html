요구사항 명세서 (SRS)

우선순위: M 꼭 있어야 함 · S 있으면 좋음 · L 다음 단계. 모든 M과 S는 이번 버전에 구현되어 있습니다.

1. 시작·계정

ID 요구사항 순위
FR-101 앱을 열면 시작 영상이 나오고, 화면을 누르면 들어간다. 소리는 버튼으로 켜고 끈다 M
FR-102 부모는 이메일·비밀번호(8자 이상)로 가입한다. 필수 동의 2개, 알림 동의는 선택 M
FR-103 이미 가입한 이메일이면 로그인으로 안내한다 M
FR-104 로그인 상태는 앱을 다시 열어도 유지된다 M
FR-105 탈퇴하면 계정·아이·기록이 모두 지워진다 M
FR-106 설정에서 시작 영상을 다시 볼 수 있다 S

2. 아이 등록

ID 요구사항 순위
FR-201 이름(8자 이내), 연령(6·7·8·9–10세), 학습 시작일(오늘~7일 뒤)을 받는다 M
FR-202 함께할 친구를 병아리·악어·고양이·토끼 중 고르거나 사진을 쓴다 M
FR-203 사진은 256px로 줄여 기기에만 저장한다. 서버에는 ‘사진 사용’ 여부만 간다 M
FR-204 설정에서 아이 정보를 바꿀 수 있다 M

3. 오늘 탭

ID 요구사항 순위
FR-301 인사 카드에 이름, 주차·주제, 캐릭터 네 마리를 시안 위치대로 보여 준다 M
FR-302 오늘 진행을 완료 수 / 전체, 분, 막대로 보여 준다 M
FR-303 오늘의 루틴을 번호가 붙은 길로 보여 준다. 정거장이 좌우로 번갈아 놓이고 점선 길로 이어진다 M
FR-304 끝낸 구간은 색이 칠해지고 정거장에 완료 표시가 붙는다 M
FR-305 길 아래로 다음 3일을 작고 흐리게 미리 보여 준다 S
FR-306 정거장을 누르면 루틴 시트가 열린다 M
FR-307 시작일 전이면 시작을 기다리는 안내를, 7일이 끝나면 마침 안내를 보여 준다 M
FR-308 주말에 하잉RTA가 켜져 있으면 찬양·바이블 스토리 정거장이 추가된다 M

4. 루틴 시트

ID 요구사항 순위
FR-401 루틴 이름, 영어 이름, 목표 분, 안내 한 줄, 오늘의 한 문장을 보여 준다 M
FR-402 “소리 놀이 시작”을 누르면 유튜브가 열리고 듣기 시간이 흐른다 M
FR-403 멈춤·이어 듣기를 할 수 있고, 앱을 닫아도 시간은 이어진다 M
FR-404 목표 시간에 닿으면 자동으로 완료된다 (timer) M
FR-405 “오늘 완료했어요”를 누르면 바로 완료되고 목표 분이 기록된다 (manual) M
FR-406 완료하면 스티커 한 장과 축하 표시를 준다 M
FR-407 한 번 완료한 루틴은 되돌리지 않는다 M

5. 소리여행·소리활동

ID 요구사항 순위
FR-501 이번 주 카드, 요일 줄(한 날 표시), 48주 4단계, 13주 미리보기 문제를 보여 준다 M
FR-502 소리활동은 단어 맞추기 → 단어 말하기 순서다 M
FR-503 맞추기 유형: 그림 고르기, 단어 고르기, 짝 맞추기, 문장 듣고 색 고르기. 8문제 M
FR-504 연령에 따라 보기 수가 달라지고, 6세는 글자를 숨긴다 M
FR-505 틀리면 정답을 알려 주고 넘어간다. 점수로 막지 않는다 M
FR-506 말하기는 기기 음성 인식으로 듣고 0.7 이상이면 통과. 두 번까지 M
FR-507 마이크를 못 쓰면 도움 모드(부모가 “잘 말했어요”)로 바뀐다 M
FR-508 맞힌 문제와 통과한 단어마다 별 1개 S
FR-509 하루에 여러 번 다시 할 수 있다 S

ID 요구사항 순위

비기능 요구사항

ID 요구사항 기준
NFR-01 반응형 320–430 폭은 꽉 차게, 그 이상은 가운데 폰 틀(최대 430)
NFR-02 성능 그림 WebP, 캐릭터 1장 30KB 안팎, 시작 영상 0.5MB
NFR-03 오프라인 영상 말고는 기기 저장만으로 동작
NFR-04 개인정보 아이는 이름·연령만. 사진은 기기에만. 광고·외부 분석 없음
NFR-05 접근성 버튼 48pt 이상, 색만으로 상태를 말하지 않음, 움직임 줄이기 존중
NFR-06 코드 품질 TypeScript strict 오류 0, 하드코딩 없음, 단위 테스트 통과
NFR-07 보안 비밀번호 argon2, JWT, 소유권 검사
NFR-08 이식성 SQLite(개발) ↔ PostgreSQL(운영) 같은 모델

제약

  • 영상은 유튜브에서 재생된다. 앱은 재생 여부를 알 수 없어 시간을 재는 방식으로 기록한다.
  • 웹의 음성 인식은 브라우저마다 다르다. 안 되면 도움 모드로 간다.
  • iOS 웹 알림은 홈 화면에 추가한 뒤에만 된다.
