비기능 요구사항

ID 항목 기준
NFR-01 성능 저사양 안드로이드(RAM 3GB)에서 화면 전환 300ms 이내. 웹 첫 로드 3G에서 3초 이내
NFR-02 오프라인 콘텐츠·그림·음성은 캐시. 진행 기록은 큐에 저장 후 온라인 시 동기화
NFR-03 접근성 터치 영역 56px 이상. 아이 화면 글자 20pt 이상, 부모 화면 16pt 이상. 색만으로 상태 구분 금지(아이콘 동반)
NFR-04 보안 HTTPS, 비밀번호 argon2 해시, JWT(액세스 15분·리프레시 30일), 사진은 서명 URL
NFR-05 개인정보 최소 수집, 탈퇴 즉시 삭제, 사진 256px 축소본만 저장, 앱 밖 노출 없음
NFR-06 호환 iOS 15+, Android 8+, iOS Safari 16.4+(웹 푸시), Android Chrome 최신 2버전
NFR-07 유지보수 콘텐츠·문구·디자인 토큰을 코드와 분리. Week 추가는 JSON 파일 하나
NFR-08 테스트 상태 계산·연속일수·문항 생성은 순수 함수로 단위 테스트
NFR-09 모션 시스템 ‘동작 줄이기’ 설정을 존중
NFR-10 안전 광고·외부 링크는 유튜브 이동 외 없음. 아이 화면에 결제·공유 요소 없음

제약

  • 유튜브 콘텐츠는 링크 이동만. 음원·영상 추출 금지 (이용약관, 지원서 약속)
  • 화면을 보지 않는 ‘듣기’는 기술로 강제할 수 없다. 앱은 시간만 잰다
  • 웹 푸시는 iOS에서 홈 화면 추가 후에만 동작한다
