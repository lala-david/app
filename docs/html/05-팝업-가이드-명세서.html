팝업·가이드 명세서

종류: D 팝업·시트(결정 필요) · G 첫 방문 가이드 · T 토스트(2초, 자동 사라짐) · B 배너(닫을 때까지)

문구 규칙: 아이용은 한 줄 + 음성. 부모용은 한 줄 설명 + 버튼 두 개 이내. 사과·전문 용어 없음. 버튼은 동작을 그대로 쓴다(“삭제”, “표시하기”).

첫 방문 가이드 (G)

한 화면에 한 번. 설정 › 안내 › “가이드 다시 보기”로 초기화. 아이용은 캐릭터가 말한다(음성 mp3).

ID 화면 대상 형태 내용 닫기
G-H1 홈 아이 오늘 노드에 스포트라이트 + 캐릭터 말풍선 🔊 “반짝이는 동그라미를 눌러봐!” 노드 탭 또는 아무 데나
G-H1b 홈 (첫 완료 후) 아이 상단 ⭐·🔥 스포트라이트 🔊 “별이 모였어! 매일 하면 불꽃이 커져” 탭
G-L1 영상 듣기 부모 카드 3장 ① 유튜브에서 틀어요 ② 앱으로 돌아오면 시간이 차 있어요 ③ 다 차면 ✓를 눌러요 “알겠어요”
G-L2 단어 맞추기 아이 캐릭터 + 손가락 애니메이션 🔊 “소리를 듣고 맞는 그림을 눌러봐” 탭
G-L3 단어 말하기 아이 마이크 버튼 스포트라이트 🔊 “듣고 따라 말해봐. 마이크를 꾹 누르고 말해” 탭
G-P1 부모 대시보드 부모 카드 3장 ① 오늘 상황 한눈에 ② 루틴표는 종이표와 같아요 ③ TV로 들었으면 빈칸을 눌러 표시하세요 “알겠어요”
G-S1 설정 부모 툴팁 1개 (알림 줄) “시간이 맞지 않으면 여기서 바꾸세요” 탭
G-G1 부모 확인 (첫 등장) 부모 시트 안 한 줄 “아이가 실수로 바꾸지 않도록 3초 눌러요” —

팝업·시트 (D)

계정

ID 트리거 제목 본문 버튼 → 결과
D-01 비밀번호 잊음 비밀번호 재설정 이메일 입력칸 “보내기” → T-01 / “닫기”
D-02 가입 중 중복 이메일 이미 가입된 이메일이에요 — “로그인하기” → A1 (이메일 채움) / “다른 이메일”
D-03 세션 만료 다시 로그인해 주세요 안전을 위해 로그인이 풀렸어요 “로그인” → A1
D-05 iOS 웹 알림 홈 화면에 추가해 주세요 그림 3단계: 공유 → 홈 화면에 추가 → 추가 “추가했어요” / “나중에”

레슨

ID 트리거 제목 본문 버튼 → 결과
D-10 레슨 중 X 그만할까요? 지금까지 한 건 저장돼요 “계속하기” / “그만하기” → H1
D-11 먼저 넘어가기 (부모 확인 후) 몇 분 들었나요? 칩: 5분 · 10분 · 15분 칩 탭 → 수동 기록 → 다음 단계
D-12 마이크 불가 부모님이 들어주세요 아이가 말하면 ✓를 눌러주세요 “✓ 말했어요” → 통과 / “건너뛰기”
D-13 유튜브 열기 실패 유튜브를 열 수 없어요 — “다시 열기” / “브라우저로 열기”
D-14 완료 노드 재탭 (시트, L0 변형) 오늘 스티커 · 단어 스티커 그림, 단어 카드 “다시 하기” → L1 (기록은 별도) / 닫기

부모 대시보드

ID 트리거 제목 본문 버튼 → 결과
D-20 월간 날짜 탭 9월 17일 (수) 루틴 4줄: 상태 · 분 · 별. 아래 배운 단어 닫기
D-21 빈칸 탭 들었어요로 표시할까요? 9/16 저녁송 · 앱 밖에서 들은 기록으로 남아요 “표시하기” / “취소”
D-22 수동 ✓ 탭 표시를 지울까요? — “지우기” / “취소”

알림·설정

ID 트리거 제목 본문 버튼 → 결과
D-30 시각 탭 (시간 선택기) 시스템 휠 “저장”
D-31 권한 거부 상태에서 알림 켜기 알림이 꺼져 있어요 기기 설정 › 알림에서 켤 수 있어요 “설정 열기” / “닫기”
D-40 하잉RTA 스위치 켬 주말 코스에 추가할까요? 토·일에 찬양율동과 바이블 스토리가 생겨요. 평일은 그대로예요 “추가하기” / “취소”
D-50 탈퇴 정말 삭제할까요? 기록·스티커·사진이 모두 지워지고 되돌릴 수 없어요. 아래에 “삭제”를 입력하세요 입력 일치 시 “삭제하기” 활성 / “취소”
D-51 로그아웃 로그아웃할까요? — “로그아웃” / “취소”
D-60 🔥 탭 연속 5일 최근 7일 칸(요일 + 불꽃/빈칸), “하루 1개만 해도 이어져요” 닫기
