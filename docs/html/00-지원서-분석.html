『The neXt』 참가지원서(하잉RTA · 선효경)를 읽고, 제품에 영향을 주는 내용만 뽑아 앱 기능과 연결한 문서입니다. 연락처·법인 정보 같은 개인정보는 옮기지 않았습니다.

읽은 자료: 참가지원서 docx, 소리노출 가이드북(최종), 소리루틴표 Week1 sample, 디자인 시안 11장(SF 폴더), 로고·캐릭터·영상 원본, 1주차 재생목록.

2. 문제 정의

지원서는 세 가지 간극을 말합니다.

  1. 고르는 부담 — 영상은 많지만 부모가 무엇을 어떤 순서로 보여 줄지 정하기 어렵다.
  2. 이어 가는 부담 — 자료를 받아도 혼자 의지로는 오래 못 간다. 밴드·카카오 채널로 독려했지만 알림과 자동화가 필요했다.
  3. 확인하는 부담 — 교사와 보호자가 아이가 실제로 했는지, 얼마나 했는지 쉽게 볼 방법이 없다.
당사자 어려움 필요한 변화 앱에서의 답
저소득층 아동 사교육비, 피드백 부족 무료 경로와 작은 성공 번호 길, 스티커, 연속일
다문화가정 아동 가정 내 영어 지원 어려움 그림·소리 중심 안내 글자 적은 화면, 캐릭터, 소리 버튼
비수도권 아동 프로그램 선택지 부족 장소 무관 모바일 학습 웹앱(PWA), 저사양 기기 고려
보호자·교사 선별·관리·확인 부담 오늘 할 일이 분명한 대시보드 오늘 탭, 부모 탭

5. ‘매일 20분’과 ‘하루 90분’

지원서는 서비스를 “매일 20분 영어 루틴”이라고 부르고, 가이드북과 소리루틴표·디자인 시안은 하루 90분(20 + 30 + 20 + 20)으로 짜여 있습니다. 두 숫자는 서로 다른 것을 셉니다.

구분 뜻 앱에서의 위치
20분 한 번에 하는 루틴 한 개의 길이. 아이가 “지금 할 일”로 만나는 단위 루틴 시트의 목표 시간, 알림 한 번
90분 하루 네 번의 루틴을 모두 했을 때의 소리노출 합계 오늘 탭의 진행 막대, 부모 탭의 “오늘 소리노출 0 / 90분”

앱은 시안과 같게 20 · 30 · 20 · 20분을 쓰고, 안내 문구는 지원서처럼 “한 번에 20분”을 앞세웁니다. 루틴 하나만 해도 그날은 연속일에 들어갑니다.

확인 필요: 공모전 심사에서 “20분”으로 통일해 보여 줄지, 가이드북의 90분을 그대로 보여 줄지는 선효경 대표님이 정해 주시면 설정값(dailyTargetMinutes, 루틴별 targetMinutes)만 바꾸면 됩니다.

8. 지원서가 요구하는 안전 기준

  • 아동 개인정보와 학습 데이터를 수익화하지 않는다 → 광고·외부 분석 도구 없음.
  • 신앙과정은 사전 동의 없이 노출하지 않는다 → 기본 꺼짐, 켤 때 확인 창.
  • 외부 유튜브 콘텐츠는 링크 방식, 링크 변경·삭제 대비 → 영상 정보는 week_routines 한 곳에서 바꾼다.
  • 단기 성과를 과장하지 않는다 → ‘완료’는 타이머·직접 누름·부모 표시를 구분해 저장한다.

9. 예산과 개발 범위

실행비 2,000만 원 중 MVP 기획·개발이 40%(800만 원)입니다. 그래서 이번 버전은 서버 비용이 거의 들지 않게 기기 저장 우선으로 만들고, 서버(FastAPI + RDB)는 파일럿에서 여러 기기·기관 통계를 볼 때 붙일 수 있게 설계만 끝내 두었습니다.
