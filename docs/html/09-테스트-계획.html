인수 기준 (유즈케이스별)

UC-01 처음 시작하기

  • 가입 후 A3 → A4 → A5 → 홈이 순서대로 뜬다
  • 필수 동의 없이는 가입 버튼이 비활성이다
  • 홈에 Day 1이 열려 있고 G-H1 가이드가 1회만 뜬다

UC-02 듣기 루틴

  • “유튜브에서 틀기” 탭 시 유튜브가 열리고 시작 시각이 저장된다
  • 앱을 나갔다 돌아와도 타이머가 경과를 반영한다
  • 20분 경과 시 버튼이 ✓ 로 바뀌고 진동·소리가 1회 난다
  • ✓ 탭 시 L4에 스티커·별이 보이고 홈 노드가 완료로 바뀐다
  • 기록에 video_status=auto, listened_min≥20 이 저장된다

UC-03 주제 루틴

  • 퀴즈 8문항이 A3·B2·C1·D2 비율로 나온다
  • 오답 시 벌점 없이 정답이 강조되고 다음으로 넘어간다
  • 말하기에서 2회 미달이면 통과 처리된다
  • 마이크 권한 거부 시 D-12 부모 모드가 뜬다

UC-04 보상

  • 4루틴 완료 시 하루 배지·컨페티·연속 +1 이 한 번만 나온다
  • Day 7 완료 시 L5 트로피와 “한 번 더” 노드가 생긴다

UC-05 아바타

  • 부위 옵션 선택이 즉시 미리보기에 반영된다
  • 저장 후 홈 상단 아바타가 바뀐다
  • 사진은 256px 원형으로 저장되고 원본은 남지 않는다

UC-06 부모 확인

  • 3초 미만에 떼면 통과되지 않는다
  • 통과 후 10분 안에는 다시 묻지 않는다

UC-07 · UC-08 대시보드·수동 체크

  • 주간 루틴표가 종이표와 같은 4×7 배치다
  • 빈칸 → D-21 → 연한 ✓. 자동 ✓는 T-20으로 거부. 미래 칸은 반응 없음
  • 수동 체크는 연속일수에 반영되지 않는다

UC-09 알림

  • 설정 시각에 알림이 오고, 완료한 루틴은 오지 않는다
  • 알림 탭 시 해당 루틴 L0 시트가 열린다
  • 테스트 알림이 10초 안에 온다 (앱·웹 각각)

UC-12 하잉RTA

  • 기본 꺼짐. 켜면 토·일에만 노드 2개가 추가되고 평일은 그대로다

UC-14 탈퇴

  • “삭제” 입력 전엔 버튼 비활성. 삭제 후 서버·기기 데이터가 없다

비기능 확인

항목 방법 기준
첫 로드 (웹) Lighthouse, 3G 스로틀 3초 이내, 초기 JS 500KB 이하
화면 전환 저사양 기기 육안·프로파일 300ms 이내

출시 전 체크리스트

  • 콘텐츠 링크 4개 재생 확인 (지역·연령 제한 없음)
  • 음성 mp3 전부 재생, 없는 파일 없음
  • 가이드 팝업 ID 전부 1회 노출 확인
  • 개인정보처리방침 링크, 탈퇴 동작
  • 웹: manifest·아이콘·서비스워커 등록, iOS 홈 화면 추가 후 알림
