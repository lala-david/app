D-12 09-19 시작 영상은 매번, 화면을 눌러 들어간다 요청 사항. 소리는 버튼으로
D-13 09-19 루틴 분은 시안대로 20 · 30 · 20 · 20, “오늘 완료했어요”는 목표 분을 기록 시안 사이트의 동작과 같게
D-14 09-19 서버는 콘텐츠까지 테이블로 정규화, 제약은 DB에 “무결성 유지” 요구. API 밖에서 들어온 값도 막는다
D-15 09-19 서버의 기록 API는 멱등 PUT, 완료는 되돌리지 않음 기기 저장이 원본이라 같은 요청이 여러 번 올 수 있다
D-16 09-19 사진은 서버에 보내지 않는다 아동 개인정보 최소 수집
D-17 09-19 시안 SVG의 좌표를 기준으로 전 화면을 다시 맞춤 첫 구현은 시안 사이트의 CSS를 따랐는데, 시안 SVG와 값이 달랐다(글자 크기, 부모·설정의 여백 16, 줄 높이 등)
D-18 09-19 본문 글꼴을 Pretendard로 시안이 Pretendard. 시스템 글꼴은 폭이 달라 줄바꿈과 크기가 어긋났다
D-19 09-19 탭 막대는 모든 탭에서 떠 있는 모양 시안은 오늘 탭만 떠 있고 나머지는 바닥에 붙은 흰 띠인데, 한 앱에서 탭마다 달라지면 어색해 오늘 탭 모양으로 통일
D-20 09-19 주간 표의 이전·다음 화살표는 유지 시안에는 없지만 지난 주를 보려면 필요. 작고 옅게

제약 영향 대응
유튜브에서 실제로 봤는지는 알 수 없다 시간은 “시작을 누른 뒤 흐른 시간” 완료 방식을 구분해 저장, 부모 표시 기능
웹 음성 인식은 브라우저마다 다르다 아이폰 사파리에서 안 될 수 있다 도움 모드
웹 알림은 앱이 열려 있을 때만 확실하다. 아이폰은 홈 화면 추가가 필요 알림이 안 올 수 있다 서버 연결 시 Web Push, 나중에 앱 출시
앱은 아직 서버에 연결되어 있지 않다 기기를 바꾸면 기록이 없다 서버·API는 완성. 연결 작업은 다음 단계
Recraft AI 그림은 쓰지 않았다 – 크레딧 약 905 남음. 키는 .env에만

다음 단계

  1. 디자이너 확인 → 길·소리활동 다듬기
  2. 앱과 서버 연결(계정 저장소 API 구현, 기록 올리기)
  3. 2–4주차 콘텐츠 JSON 추가
  4. 교사용 여러 아이 보기
  5. 앱 스토어용 빌드(EAS)
