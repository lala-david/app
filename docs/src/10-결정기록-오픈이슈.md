## 알려진 제약

- 유튜브 시청 중 광고·추천 영상은 막을 수 없다 (앱 밖)
- 웹 푸시는 iOS에서 홈 화면 추가 후에만 온다
- Web Speech API는 브라우저·언어 지원이 다르다. 실패 시 부모 모드로 안전하게 빠진다
- 영상 4개 모두 목표 시간보다 길다. 타이머가 기준이다
