## 화면 구성

네 개의 탭과 그 위에 뜨는 화면입니다.

| 탭 | 내용 | 시안 |
|---|---|---|
| 오늘 | 인사 카드, 오늘 진행, **루틴 길(1·2·3·4)**, 루틴 시트 | 01, 05A–D |
| 소리여행 | 이번 주 카드, 소리활동 들어가기, 요일 줄, 48주 단계, 13주 미리보기 | 02 |
| 부모 | 요약 네 칸, 오늘·주간·월간, 이번 주 한눈에, 모은 스티커 | 03A–C |
| 설정 | 알림, 저녁 리마인드, 하잉RTA 주말, 아이 정보, 안내, 계정 | 04 |

그 밖: 시작 영상(00), 로그인·가입, 아이 등록, 소리활동(단어 맞추기·말하기).

## 포함

- 시작 영상 → 화면을 눌러 들어가기
- 부모 계정 가입·로그인, 아이 등록(이름·연령·시작일·친구 4종 또는 사진)
- 하루 4개 루틴: 앱 안에서 영상 보기, 듣기 시간 재기, 자동 완료와 직접 완료
- 번호 길: 오늘과 다음 3일, 완료 구간 색칠, 캐릭터
- 소리활동: 단어 맞추기(4유형) → 단어 말하기(음성 인식, 도움 모드), 별
- 스티커 판(6칸씩), 연속일
- 부모 탭: 오늘·주간 표·월간 달력, ‘들었어요’ 표시·해제
- 루틴 알림, 저녁 리마인드, 하잉RTA 주말 콘텐츠 선택
- 서버 설계와 구현: 스키마, API, 무결성 테스트

## 제외

| 제외 | 이유 | 준비해 둔 것 |
|---|---|---|
| 부모 확인(잠금) | MVP에서는 빼기로 결정 | 부모 탭은 바로 열린다 |
| 2주차 이후, 파닉스 | 이번은 1주차만 | `weeks` 테이블, 여정 화면 |
| 간단 진단 | 연령 선택으로 대신 | 난이도 설정값 |
| 교사·기관 대시보드 | 파일럿 단계 | `events`, 리포트 API |
| 서버 동기화 연결 | 기기 저장으로 충분 | 계정 저장소 인터페이스, API |
| 앱 안 영상 재생 | 구현함 (D-26) | 유튜브 IFrame 플레이어 |

## 원칙

1. 아이 화면은 읽지 않아도 쓸 수 있어야 한다.
2. 시안과 같게 만든다. 값은 디자인 토큰 한 곳에 둔다.
3. 글·숫자·색·콘텐츠를 코드에 박지 않는다. JSON과 토큰, 문구 파일에 둔다.
4. 기록은 거짓이 없어야 한다. 어떻게 완료했는지(타이머·직접·부모)를 구분한다.
5. 아이 정보는 최소로. 사진은 기기를 떠나지 않는다.
6. 신앙 콘텐츠는 부모가 켤 때만.
