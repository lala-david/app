# 비전과 범위

| 항목 | 내용 |
|---|---|
| 제품명 | 사운즈펀 브릿지 (SoundsFun Bridge) |
| 한 줄 | 아이가 매일 4번, 영어 소리에 놀듯이 노출되는 루틴 앱 |
| 버전 | MVP · Week 1 ‘Colors’ |
| 플랫폼 | 모바일 앱(iOS·Android) + 모바일 웹, 코드 한 벌(Expo) |
| 작성 | 2026-09-16 · 강성준 |

## 문제

유튜브에 좋은 영어 노래·스토리는 많지만, 부모가 매일 무엇을 언제 틀지 정하고 챙기는 일은 지속되지 않는다. 종이 루틴표와 QR로 운영해 보니 알림과 기록이 없어 습관이 끊겼다.

## 해결

가이드북의 하루 90분 소리루틴을 그대로 앱의 코스로 옮긴다.

| 루틴 | 시간 | 방식 | 앱에서 하는 일 |
|---|---|---|---|
| ☀ 아침송 | 20분 | 듣기만 | 유튜브 링크 열기 → 타이머 → 완료 스티커 |
| 🎨 주제 집중듣기 | 30분 | 보기 + 놀이 | 영상 → 단어 맞추기 → 단어 말하기 |
| 🍽 저녁송 | 20분 | 듣기만 | 유튜브 링크 열기 → 타이머 → 완료 스티커 |
| 🌙 잠자리 스토리 | 20분 | 듣기만 | 유튜브 링크 열기 → 타이머 → 완료 스티커 |

화면을 보는 루틴은 주제 집중듣기 하나뿐이다. 나머지는 틀어 두고 생활하면 된다.

## 사용자

| 사용자 | 역할 | 화면 |
|---|---|---|
| **아이 (6~10세, 주 사용자)** | 코스 맵에서 오늘 루틴을 누르고, 주제 놀이를 하고, 스티커를 받는다 | 홈, 레슨, 보상 |
| 부모 | 계정·시간·알림을 관리하고 기록을 본다. 영어 실력 불필요 | 부모 대시보드, 설정 |

아이 화면은 글자를 최소로 하고 모든 안내를 그림과 소리로 준다. 부모 화면은 큰 글자와 한 줄에 하나씩, 전문 용어 없이 만든다.

## 목표 (파일럿 지표)

| 구분 | 지표 |
|---|---|
| 실천 | 루틴별 시작·완료율, 하루 90분 달성률, 4주 잔존율 |
| 학습 | 주제 단어 정답률, 말하기 시도율 |
| 부모 | “오늘 뭐 틀지” 고민 시간 감소, 재사용 의향 |

## 범위

### 포함
- 회원가입·로그인, 아이 프로필(아바타 꾸미기 또는 얼굴 사진)
- 코스 맵: Day 1~7, 하루 4루틴 노드, 연속일수
- 듣기 루틴 3종: 유튜브 링크 + 타이머 + 완료
- 주제 루틴: 영상 → 단어 맞추기 → 단어 말하기(음성인식)
- 보상: 별, 스티커, 하루 완료 배지, 연속일수, 주간 트로피
- 부모 확인 게이트, 부모 대시보드(요약·주간 루틴표·월간·통계)
- 알림: 루틴 시각(앱 로컬 알림 / 웹 푸시)
- 설정: 알림 시간, 아이 프로필, 하잉RTA 주말 콘텐츠 스위치, 안내·FAQ, 계정 삭제
- 기능마다 첫 방문 가이드 팝업

### 제외 (구조만 준비)
- Week 2 이후 콘텐츠, 파닉스·읽기·쓰기
- 앱 내 유튜브 재생, 광고 처리
- 교사·기관 대시보드, 다국어, 소셜 로그인
- 하잉RTA Read–Talk–Apply 과정 자체

## 원칙

| 원칙 | 구현 |
|---|---|
| ‘많이’보다 ‘매일’ | 하루 단위 코스, 연속일수, 즉시 보상. 한 주 내내 같은 영상 반복 |
| 생활 속 소리 배치 | 알림이 생활시간에 오고, 영상은 유튜브에서 틀고 앱은 시간만 잰다 |
| 강요 없는 말하기 | 말하기는 건너뛸 수 있고 실패해도 통과. 벌점·하트 없음 |
| 부모 준비 0 | 오늘 카드에 “지금 틀 영상” 하나만 |
| 공공 영어와 신앙교육 분리 | 하잉RTA는 부모가 켤 때만, 기본 꺼짐 |
| 개인정보 최소 | 아이 실명·생년월일 없음 |
