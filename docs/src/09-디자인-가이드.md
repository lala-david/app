# 디자인 가이드

차진숙 디자이너의 시안(SF 폴더 SVG 11장)에서 값을 가져왔습니다. 시안 SVG는 피그마에서 뽑은 것이라 모든 도형의 좌표·크기·색이 정확히 들어 있어, 도형은 그대로 읽고 글자는 글꼴을 입혀 폭과 높이를 맞춰 보는 방식으로 크기를 역산했습니다. 모든 값은 `apps/mobile/src/shared/theme/tokens.ts` 한 파일에 있고, 화면 코드는 이름으로만 씁니다.

## 원칙

1. 시안과 같게. 눈대중이 아니라 시안 SVG에서 읽은 값을 쓴다. 시안과 앱을 나란히 붙인 비교 이미지로 확인한다.
2. 아이 화면은 밝고 둥글게, 부모 화면은 차분하고 또렷하게.
3. 글보다 그림. 상태는 색과 모양 둘 다로 알린다.
4. 새로 디자인한 것은 **루틴 길** 하나. 나머지는 시안 그대로.

## 캐릭터

| 캐릭터 | 파일 | 맡은 루틴 |
|---|---|---|
| 병아리 | `characters/chick.webp` | 아침 노래 |
| 악어 | `characters/crocodile.webp` | 오늘의 주제 |
| 고양이 | `characters/cat.webp` | 저녁 노래 |
| 토끼 | `characters/rabbit.webp` | 잠자리 이야기 |

원본 PNG(약 1MB)를 640×640 WebP(약 30KB)로 바꿔 씁니다. 디자이너 원본에는 둘레 여백이 있어서, 시안의 그림 상자 크기를 그대로 받고 캐릭터는 상자의 88%로 그립니다(`sizes.characterFill`).

인사 카드 안의 위치는 시안 SVG에 들어 있는 캐릭터 그림의 실제 그림 영역을 계산해 맞췄습니다(카드 왼쪽 위 기준, 뒤에서 앞 순서).

| 캐릭터 | 상자 크기 | 왼쪽 | 위 |
|---|---|---|---|
| 악어 | 126 | 219 | 39 |
| 토끼 | 99 | 129 | 162 |
| 고양이 | 107 | 259 | 142 |
| 병아리 | 148 | 173 | 138 |

캐릭터는 3.2초 주기로 위아래로 살짝 둥실거립니다. 기기에서 움직임 줄이기를 켜면 멈춥니다.

## 루틴 길 (새 디자인)

시안의 TODAY’S ROUTINE 목록 자리에 들어가는 디자인입니다. 디자이너의 캐릭터와 루틴 색을 그대로 써서 시안과 어울리게 했습니다.

| 요소 | 디자인 |
|---|---|
| 정거장 | 루틴 파스텔 색의 둥근 돌. 아래에 강조색으로 두께를 주어 입체로 보인다. 그 위에 캐릭터 |
| 번호 | 정거장 왼쪽 위의 흰 동그라미, 강조색 숫자 |
| 길 | 회색 점선 곡선. 끝낸 구간은 그 루틴의 강조색 실선 |
| 이름표 | 정거장 반대쪽의 흰 카드: 이름, 영어 이름, 분, 재생 버튼 |
| 완료 | 정거장에 초록 체크, 이름표에 “완료” 알약 |
| 날짜 | 길 머리에 `DAY 1 · 오늘` 알약 |
| 다음 날 | 70% 크기, 흐리게, 점선 동그라미 |

> Recraft AI로 길 배경 그림을 시험해 봤지만 시안의 캐릭터와 그림체가 맞지 않아 쓰지 않았습니다. 길은 SVG와 코드로 그려서 화면 폭에 맞게 늘어나고, 색도 토큰을 따릅니다.

## 문구

- 아이에게 보이는 말은 짧게, 해요체로. “소리 놀이 시작”, “오늘 완료했어요”.
- 점수·등수·실패 같은 말은 쓰지 않는다. 틀리면 정답을 알려 준다.
- 부모에게는 숫자를 먼저: `20 / 90분`, `1 / 28`.
- 영어는 콘텐츠(루틴 영어 이름, 한 문장, 단어)에만.
