# 팝업·가이드 명세서

종류: **D** 팝업·시트(결정 필요) · **G** 첫 방문 가이드 · **T** 토스트(2초, 자동 사라짐) · **B** 배너(닫을 때까지)

문구 규칙: 아이용은 한 줄 + 음성. 부모용은 한 줄 설명 + 버튼 두 개 이내. 사과·전문 용어 없음. 버튼은 동작을 그대로 쓴다(“삭제”, “표시하기”).

## 첫 방문 가이드 (G)
