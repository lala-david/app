## 시안과 비교

시안 SVG와 앱을 같은 폭으로 찍어 좌우로 붙인 비교 이미지를 화면마다 만들어 확인합니다(오늘, 루틴 시트 2종, 소리여행, 부모 오늘·주간·월간, 설정).

| 단계 | 방법 |
|---|---|
| 도형 | 시안 SVG의 모든 도형을 브라우저에서 `getBBox()`로 읽어 좌표·크기·색 표를 만든다 |
| 글자 | 시안의 글자는 윤곽선이라, 후보 글꼴로 같은 문장을 그려 잉크 폭·높이가 맞는 크기를 찾는다 |
| 캐릭터 | SVG에 박힌 PNG의 투명 여백을 걷어 내 실제 그림 영역을 계산한다 |
| 확인 | 고친 뒤 다시 찍어 붙여 어긋난 곳을 본다 |

루틴 길만 새 디자인이고, 설정의 추가 줄 3개(알림 시간·저녁 리마인드·하잉RTA)와 주간 표의 화살표는 합의된 차이입니다.
